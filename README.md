# Verdens Beste Musikkskole – juksebøker og lytteguider

Static website with music theory materials by Verdens Beste Musikklærer.
Start page: `index.html`. All pages are self-contained HTML (no external files).

## Publish on GitHub Pages
1. Upload all files in this folder (not the folder itself) to a public repository.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. After 1–2 minutes the site is live at `https://<username>.github.io/<repository>/`.

To update a page, upload a new file with the same name.
